IMAGE STUDIO - CHROME EXTENSION

CÀI LẦN ĐẦU
1. Giải nén thư mục Image-Studio-Chrome.
2. Mở Chrome và nhập: chrome://extensions
3. Bật "Chế độ dành cho nhà phát triển" / Developer mode.
4. Bấm "Tải tiện ích đã giải nén" / Load unpacked.
5. Chọn đúng thư mục Image-Studio-Chrome.
6. Ghim Image Studio lên thanh công cụ Chrome.

CÁCH DÙNG
- Bấm icon Image Studio -> "Mở Image Studio".
- Trong cửa sổ tool có nút "Cập nhật từ GitHub" ở phía trên.
- Nút này kiểm tra GitHub, bỏ cache và nạp tool mới nhất ngay.

KHI EXTENSION CORE CÓ BẢN MỚI
- Popup sẽ hiện nút "Tải extension mới".
- Tải ZIP, giải nén và thay nội dung thư mục cũ.
- Quay lại chrome://extensions và bấm Reload ở Image Studio.

LƯU Ý
Chrome không cho extension tự thay mã nguồn của chính nó. Vì vậy tool trên GitHub có thể nạp mới ngay,
nhưng bản manifest/popup của extension phải cập nhật bằng ZIP + Reload khi có thay đổi.
